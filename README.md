# Сучасні блокчейн-технології — лабораторні роботи та проєкт

| Робота | Що зроблено | Код |
|---|---|---|
| **ЛР № 1** — користувачі та транзакції | БД CNUCoin (5 таблиць за Додатком), SHA-256 + ECDSA secp256k1, реєстрація з чекбоксом «майнер», підписані транзакції | [CNUCoin/](CNUCoin/) |
| **ЛР № 2** — майнінг | Proof-of-Work з перебором Nonce, винагорода 5 %, підтвердження наступним блоком, аудит ланцюжка, виявлення підробки, дослід складності | [CNUCoin/](CNUCoin/) |
| **Проєкт** (варіант № 10) — **AidChain** | Блокчейн-реєстр прозорого обліку благодійної допомоги: Ed25519, дерево Меркла, PoW, 3 вузли з консенсусом Накамото, «смарт-контракт» правил, трасування донату, перевірка документів, демонстрація атак і форку | [AidChain/](AidChain/) |

## Встановлення

```bash
pip install -r requirements.txt
```

## CNUCoin (ЛР № 1 і № 2)

```bash
cd CNUCoin
python lab1_protocol.py     # ЛР 1: нова БД, реєстрація, перша транзакція  -> output/lab1_protocol.txt
python lab2_protocol.py     # ЛР 2: майнінг, підтвердження, атака, дослід   -> output/lab2_protocol.txt
python web/app.py           # веб-інтерфейс: http://127.0.0.1:5000  (кнопка «Заповнити демо-даними»)
python -m pytest            # 9 тестів
```

## AidChain (проєкт)

```bash
cd AidChain
python app.py               # http://127.0.0.1:8000
python -m pytest            # 12 тестів
```

Що показати на захисті:
1. **Мережа вузлів** — натиснути «⛏ Майнити» на будь-якому вузлі: блок з'являється на всіх трьох.
2. **Дії учасника** — обрати донора, зробити донат → він потрапляє в mempool → змайнити.
3. **Куди пішли мої гроші?** — частка донора в кожній закупівлі та статус доставки з номерами блоків.
4. **Перевірка документа** — завантажити `samples/invoice_drones.txt` (✔ справжній) і `invoice_drones_FORGED.txt` (✘ підробка).
5. **Атака** — «☠ Атака» на вузлі Львів, блок 3, з галочкою «перемайнити» → вузол червоний, бо ЕЦП не підробити → «⇄ Консенсус» лікує вузол.
6. **Форк** — «Відключити» Чернівці, змайнити там і двічі в Києві, «Підключити» → перемагає довший ланцюжок.
7. Клік по блоку → 7 перевірок, транзакції, «Доведення Меркла».

«↺ Скинути демо» відтворює сценарій. Усі організації та люди в демо вигадані.

## Звіти

Звіти (.docx + .pdf) не входять до репозиторію й генеруються в папку `Звіти/`. Титульна сторінка береться з шаблону кафедри `lab_1.docx`; тема, дисципліна та викладач підставляються автоматично (див. `reports/docgen.py`).

Перегенерувати звіти (після запуску протоколів і тестів; потрібен шаблон титулки `lab_1.docx` у корені, він не входить до репозиторію):

```bash
cd reports
python build_lab1.py && python build_lab2.py && python build_project.py
```
Після цього відкрийте документ у Word і оновіть зміст (F9).
